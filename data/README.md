# Data

`raw/sample_cell_measurements.csv` contains synthetic raw-style cellular telemetry.

The dataset is intentionally imperfect. Missing measurements, duplicated records,
inconsistent network labels, malformed timestamps, text inside numeric columns,
and out-of-range values are included so that the preprocessing code has realistic
data-quality problems to handle.

The data is synthetic and does not contain customer, device, subscriber, or
commercial network information.

`processed/` is generated by the training pipeline and is intentionally excluded
from Git tracking.
